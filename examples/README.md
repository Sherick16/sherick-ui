# Examples

- [Application sidebar](sidebar/) — copyable desktop navigation and mobile drawer. Run `bun run dev` and visit `/examples/sidebar/overview` for a live preview.
- [Workspace settings](settings/) — validated settings form with Save/Cancel and destructive confirmation. Run `bun run dev` and visit `/examples/settings` for a live preview.
- [Searchable project list](resources/) — table with search, filters, sorting, pagination and distinct empty states. Run `bun run dev` and visit `/examples/resources` for a live preview.
- [Project detail](detail/) — breadcrumb, contextual actions, tabbed views and metadata. Run `bun run dev` and visit `/examples/resources/customer-portal` for a live preview.
